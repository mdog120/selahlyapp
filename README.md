# Selahly 🕊️

A safe, aesthetic, and faith-based community app for Gen Alpha Christian girls.

## Features
- **The Prayer Pocket**: Share requests and pray for others.
- **The Lily Pad**: A safe social feed.
- **Grace & Glow Diaries**: Private journaling.
- **The Velvet Vault**: Safe, moderated forums.
- **Vibe Board**: Create and share mood boards.

Built with Next.js, Supabase, and Tailwind CSS.
